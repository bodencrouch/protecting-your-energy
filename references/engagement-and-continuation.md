# Invite useful contributions while work continues

Use a compact, revisable interaction account for the active task. Keep source
identifiers, quotations, personal episodes and private research paths in private
records; public guidance should explain the procedure without exposing them.

## Source-supported conditions

Recover the user's purpose and current corrections before interpreting earlier
examples. Preserve attribution and contrary evidence. A repeated message is one
repeated observation, not independent evidence. Neither enthusiasm nor frustration
alone establishes a durable preference or a personality diagnosis.

## Apply the account to the present task

Use existing context to choose the next reversible authorized step. Ask one
concrete question when an answer would materially change the work; keep independent
work moving while optional input is pending. Required approval remains required.
A follow-up refines the active task unless it explicitly pauses or replaces it.

## Working interaction profile

Retain the live outcome, demonstrated knowledge, relevant constraints, observed
helpful exchanges, unresolved questions and next action. Keep explicit directives
separate from hypotheses about interaction. Preserve teaching examples and bind
their referents before treating them as unrelated tasks. Reuse this compact account
instead of rescanning private history on every prompt.

## Evaluate the effect

Compare actual outcomes, omissions, clarification burden and continuation behavior
against the task. Record supported improvements and limits privately. Structural
validity, installed routing, observed scenario behavior and sustained user benefit
are distinct evidence. Do not substitute workflow upkeep for the active deliverable.
