# Place agent guidance where it belongs

Keep one authoritative home for each concern and reference it from adapters.
Reminders do not enforce semantic completeness or prove task completion.

| Concern | Primary mechanism | Supporting mechanism |
| --- | --- | --- |
| Stable constraint or execution invariant | Scoped rule / host instructions | Short event-time reminder |
| Project authority paths and explicit decisions | Project guidance or private memory | Retrieve into the active task |
| Active tasks, dependencies and completion evidence | Durable task ledger | Hook surfaces pending work |
| Reusable expert procedure and phase selection | Skill, command or agent role | Small rule routes to it |
| Deterministic event checks | Supported host hook/script | Failure logs and stated limits |
| Existing Git work | Review and integration procedure; scoped publication rule | Ledger holds unfinished groups |
| Incident explanations and hypotheses | Private audit or memory | Promote only supported authorized changes |

Message coverage and continuity belong in instructions; current tasks belong in
continuation state. A prompt hook surfaces that state without treating follow-ups
as cancellation. The agent still reconciles every request and question with actual
outcomes. Lexical checks cannot establish complete semantic coverage.

Context recovery is a rule plus a retrieval skill: recover material uncertainty
before interpreting, then use source inspection and attribution. A routing hook
must not force routine requests through archive searches. Scope words preserve the
user's breadth but do not prove the search found every relevant item.

Consolidation destinations belong in project guidance and private memory. The
procedure inspects the established authority layout, reconciles conflicts, verifies
content and records provenance. Keep private machine paths out of public rules.

Use workflow-orchestration for capability discovery and phase-aware selection.
An explicit durable user preference can require that checkpoint for substantial
work. Existing host hooks can remind the agent at task/phase boundaries; they
should not guess a workflow from keywords, force irrelevant invocations, create
permission, or claim installation without evidence.

Prefer existing supported host hooks. This plugin ships portable skills; it has
no declared hook integration. Do not add speculative hook manifests or silently
install global configuration as part of distributing a skill.
