# Choose the next action

Recover current goals, explicit priorities, obligations, real deadlines,
dependencies, active owners and the most recent project state. Read the private
[continuity record](../../references/continuity.md) and relevant thread/artifact
sources. Treat summaries as leads; confirm a material constraint from its source
when possible. Do not label silence as abandonment or unpleasant work as
avoidance without evidence.

Compare a small set of actual candidates by: benefit toward the stated goal,
readiness, changed opportunity, remaining active effort, waiting/dependencies,
proof needed and the cost of interruption. Obligations are not optional merely
because another task has more visibility. Already-running agents and jobs have
owners; avoid duplicating or redirecting their work without authority.

Use comparable completed work for effort estimates when available. State ranges
and their basis; sparse anecdotes are not calibrated percentiles. If remaining
effort is unknown, choose a cheap information-producing action when it changes
the decision. A chosen work budget is not a duration prediction. Separate machine
waiting from owner attention. Past effort alone does not justify continuing. Preserve ambition and the
current productive rhythm when the evidence supports them. Distinguish chosen
pace, unmet obligations and avoidable friction.

Select one next action with a concrete result and completion point. Preserve
the wider objective and any deferred work. Do not silently lower proof or drop
requirements to make a task seem finished. Use `finish-loop` when a changed
forecast requires reassessment; use `opportunity-radar` to verify an external
signal before it becomes a priority.

If the owner has not provided today's capacity or calendar, give a provisional
choice from known work and make its dependency clear. Never invent appointments,
mood, urgency or available hours. Ask only for a missing choice that materially
changes the result after independent work is complete.

Return the chosen action and a short reason it beats the nearest alternative.
Keep the full comparison privately. Record the decision, basis, completion
condition and resumption link so the next request does not restart the analysis.
